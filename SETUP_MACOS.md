# macOS Setup

Install [Ghostty](https://ghostty.org) by hand, then run this from it:

```bash
bash -c "$(curl -fsSL https://raw.githubusercontent.com/piacsek/dotfiles/main/scripts/bootstrap_macos.sh)"
```

[`scripts/bootstrap_macos.sh`](scripts/bootstrap_macos.sh) is the setup. It is safe to rerun, and it ends with the steps that stay manual.

Glove80 won't pair over Bluetooth? See [MoErgo troubleshooting](https://docs.moergo.com/glove80-user-guide/troubleshooting/).
